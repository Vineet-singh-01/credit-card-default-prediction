# Five-member work plan

| Member | Lead area | Evidence/deliverables |
|---|---|---|
| 1 | Business case and dataset provenance | Business problem, target, source and data dictionary |
| 2 | Data audit and EDA | Data-quality checks, visualisations and written insights |
| 3 | ML development | Preprocessing rationale, model comparison and reproducibility |
| 4 | Evaluation and business interpretation | Metrics, threshold costs, calibration and fairness review |
| 5 | Streamlit, GitHub and release | App tests, repository coordination, README and deployment |

All members should review at least one other workstream and be prepared to explain the complete project.
