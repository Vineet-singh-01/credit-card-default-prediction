# GitHub and Streamlit deployment

Repository: https://github.com/Vineet-singh-01/credit-card-default-prediction

The text source, notebooks, audit, metrics and reports are published. The raw workbook and customer-level CSV are intentionally excluded from this public repository. The trained binary joblib model is not included in the text-file publishing commit.

## Add the model artifact
From the downloaded project ZIP, copy `models/credit_default_pipeline.joblib` into the repository's `models/` directory using a local Git client. Confirm it was generated by this project and works with the declared scikit-learn/joblib versions. Do not load joblib files from untrusted sources.

## Deploy
1. Push the model artifact and all required files to the public repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Create an app from repository `Vineet-singh-01/credit-card-default-prediction`, branch `main`, main file `app.py`.
4. Wait for the build; test all three pages and one prediction.
5. Check deployment logs and correct dependency/path errors.
6. Add the live URL to README only after public-browser testing.

No secrets are needed for this prototype. Never commit tokens or credentials.
