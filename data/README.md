# Data directory

The project uses the **Default of Credit Card Clients** dataset from the UCI Machine Learning Repository.

- Official source: https://archive.ics.uci.edu/dataset/350/default%2Bof%2Bcredit%2Bcard%2Bclients
- DOI: https://doi.org/10.24432/C55S3H
- Target column: `default payment next month`
- Target values: `1` = default, `0` = no default

## Local setup

1. Download the original dataset from the official UCI page.
2. Keep an unchanged copy of the downloaded source file locally.
3. Record the source filename and any extraction steps in the project notebook.
4. Do not overwrite the original file during cleaning; create a separate working DataFrame.

The team will decide whether to include the original openly licensed source file in this public repository after checking the downloaded file and retaining the required attribution. Do not commit personal, confidential, or unrelated data here.

Dataset-specific findings should only be documented after the file has been loaded and inspected.
